# DUMA Fleet

**Tagline:** Smart Fleet Management. Built for Africa. Ready for the World.

DUMA Fleet is a fleet-management app for businesses of all sizes. Manage vehicles, drivers, trips, GPS location records, fuel expenses and maintenance in one place. Designed for African operators with a path to serve businesses worldwide.

The current Android build is an offline-first MVP. Records are stored locally on the device. GPS capture records the last known location when requested; it is not continuous live tracking.
